# 🩺 HealthEase – Web Based Patient Doctor Appointment Portal

A modern and user-friendly web application designed to simplify the appointment booking process between patients and doctors. The system provides secure authentication, appointment scheduling, doctor search functionality, slot management, and an admin dashboard for managing the complete healthcare appointment workflow.

---

# 📌 Project Overview

HealthEase is a web-based Patient Doctor Appointment Portal developed to improve the efficiency of appointment management in healthcare systems. The platform allows patients to search doctors based on specialization, location, and consultation fee, while doctors can manage their schedules and appointments effectively.

The project focuses on creating a simple, responsive, and secure system that enhances communication between patients and healthcare providers.

# 🏗️ System Architecture

The project follows a simple three-layer architecture:

## Frontend Layer

User Interface using HTML, CSS, and JavaScript

## Backend Layer

Python-based server-side logic  
Handles routing, validation, and appointment logic

## Database Layer

SQLite database for storing:

- Patients
- Doctors
- Appointments
- Slot Information
