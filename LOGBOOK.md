## Week 3 : Requirement Analysis & System Overview

**Date:** 18/08/2025 – 23/08/2025

**Activities Completed**

We identified the needs of patients and doctors and listed the functional requirements such as user login, doctor search, appointment booking, and appointment management. We also discussed non-functional requirements like security, performance, and ease of use. A basic system overview was prepared to understand how the system will work.

**Next Plan**

Design the system architecture and decide system modules.

**Guide Interaction**

Guide reviewed the requirement analysis and suggested clearly separating patient and doctor modules for better system clarity.



## Week 4 : System Architecture Design 

**Date:** 28/08/2025 – 02/09/2025

**Activities Completed**

The system was divided into modules such as patient module, doctor module, and admin module. We decided to use HTML, CSS, and JavaScript for frontend development and Python with SQLite database for backend development. The interaction between frontend, backend, and database was discussed and a basic system flow was prepared.

**Next Plan**

Start Phase 1 of implementation using selected frontend and backend technologies.

**Guide Interaction**

Guide reviewed the architecture and suggested using Python and SQLite for easy database handling and keeping the frontend simple and responsive.


## Week 5 : Phase 1 of Implementation

**Date:** 03/09/2025 – 13/09/2025

**Activities Completed**

Basic frontend pages were created using HTML and CSS. User interface for patient and doctor login was designed. Backend work was started using Python and database tables were created in SQLite. Basic connection between frontend and backend was tested.

**Next Plan**

Continue implementation and add appointment booking functionality.

**Guide Interaction**

Guide reviewed the initial implementation and suggested improving page layout and validating user login properly.



## Week 6 : Combined Design & Implementation

**Date:** 15/09/2025 – 20/09/2025

**Activities Completed**

Patient and doctor registration functionality was implemented. Backend routes were created using Python to handle registration, login, and appointment-related requests. Database tables for patient, doctor, appointments, and slots were designed in SQLite. A doctor search page was implemented where patients can find doctors using filters such as location, consultation fee, and specialty. Basic dashboards for patient, doctor, and admin were designed.

**Next Plan**

Implement appointment booking, dashboards features, and slot management.

**Guide Interaction**

Guide reviewed the combined work and suggested proper validation, structured backend routes, and clear separation of dashboards for patient, doctor, and admin.

## Week 7 : Phase 2 of Implementation

**Date:** 22/09/2025 – 04/10/2025

**Activities Completed**

Appointment booking functionality was implemented for patients. Patient dashboard was developed with features such as Book Appointment, My Appointments, and My Profile. Doctor dashboard was implemented with features like My Appointments, My Profile, and Slot Settings for managing available time slots. Backend routes were enhanced using Python to handle appointment booking, slot availability, and user profile management. Database tables were updated in SQLite to store appointment and slot details.

**Next Plan**

Implement admin panel and improve backend validation.

**Guide Interaction**

Guide reviewed the implementation and suggested improving appointment flow, handling slot conflicts properly, and securing backend routes.

## Week 8 : Phase 3 of Implementation
